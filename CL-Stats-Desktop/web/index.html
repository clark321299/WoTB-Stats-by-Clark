Архів взводів
Пояснення
  • «Цей захід» — ігровий день з 05:00 у поточному пулі (усі сьогоднішні катки, і після свічу акаунта).
  • Прогноз зверху — окремо: ~1.5 год паузи. «Увесь архів» — старі дні. Клік по рядку — розбір; «аналізувати» — реплей.
  • «Наживо» — склад із live-реплею під час бою. «Історія боїв» — підсумок після бою.

Аналіз бою

Розбір бою зверху по реплею: рух, таймлайн, засвіти. З каток — кнопка «аналізувати» у списку.

Налаштування

Тема, мова, експорт/імпорт — у верхній смузі. Тут — рідкісні сервісні речі.

  • Тема й мова — у верхній смузі справа
  • Експорт / імпорт зверху — повна копія (zip). Старий JSON — кнопка «Додати з JSON» нижче.
  • Шляхи — якщо авто не знайшло Data гри чи реплеї
  • ТТХ — лише коли DPM/клас не збігаються з ангаром
  • Акаунти Оленімера — основа / статистика / твінк (нижче)

Допис сесій і архіву з веба (blitzstats-backup) або зі старого десктопу. Реплеї не замінює, дублі не додає. Повна копія — zip зверху.

Підтягує танки з папки Data гри. Збережені DPM 🔒 не чіпаються.
